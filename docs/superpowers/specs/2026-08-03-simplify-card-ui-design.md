# Упрощение интерфейса карточек

## Цель
Уменьшить визуальную нагрузку без изменения базы данных, API и анализа уроков.

## Преподаватель
- Не показывать в черновиках поля `definition_en`, `source_phrase`, `level`.
- Не показывать `definition_en` в опубликованной карточке.
- Оставить слово, перевод, пример, изображение и атрибуцию.
- При сохранении видимых полей сохранять прежние значения скрытых полей, а не очищать их.

## Ученик
- Убрать тексты «Сначала вспоминаем перевод сами» и «Выберите, насколько хорошо помните слово».
- Сохранить переворот карточки и кнопки «Учу»/«Знаю».

## Проверка
- Исполняемые Node-тесты подтверждают отсутствие текстов/полей и сохранение скрытых значений в payload.
- Полный `./scripts/test_all.sh` остаётся зелёным.
